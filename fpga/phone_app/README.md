# 弦外之芯音游与蓝牙控制台

本版提供真实网页按键计分、自然演奏演示、浏览器声音实验和电脑串口连接控制。双击 `启动手机控制台.bat`，将命令窗口中的完整地址复制到浏览器。手机与电脑应在同一 Wi-Fi，首次发声需要点击页面按钮。

## 推荐拍摄顺序

1. 点击“自然演奏演示”：3 秒准备，当前曲目演奏四遍。小蜜蜂在 BPM 112 时约 56 秒完成。演示包含自然力度、约 ±30 ms 的起音时差、短暂释音和琴键点亮。
2. 点击“拍摄视图”收起侧栏，保留自动演奏标识。浏览器合成音可用于介绍网页体验，不能配到板上画面冒充 FPGA 录音。
3. 点击“开始真人练习”：电脑按 A S D F J K L 分号，或在手机上触摸八个琴键。当前版本判定起音，长音尾部仅提示时值。±55 ms 为 PERFECT，±145 ms 为 GOOD；漏音和错音断连击。同一个音符不能重复得分。
4. 在声音实验区调节力度、滑音时间和颤音深度；选择四种试听音色，点击 4／8／16／32 声部。每个声部有独立振荡器和包络，3 秒后释放。这些参数仅控制浏览器，不下发 FPGA。
5. 需要板上效果时使用现有自动演示：第 2 段力度，第 13 段滑音，第 14 段颤音，第 15–18 段分别为 4／8／16／32 声部。拍到开发板屏幕并录下 DAC 实际声音。

## 没有 CP2102 如何连接

新 JDY-31 常见出厂 UART 为 9600。本版 FPGA 接收器默认 9600，内部曲谱回环同步改为相同速率；旧联调增强版固件仍是 115200。无需为了匹配本版而发送 AT+BAUD8。

JDY-31 TXD → J22 第 12 脚 M26；GND → J22 第 3 或 4 脚。VCC 根据模块实物的额定输入选择；四针数量不能证明其有 5 V 稳压底板。进入 FPGA 的 TXD 必须是 3.3 V 逻辑。本版没有 FPGA 到 JDY-31 的回传线。

电脑有蓝牙适配器时，在 Windows 配对 JDY-31，选择出站 SPP COM 口。打开网页，刷新串口列表，选该口，点击连接。“串口已打开”只代表电脑串口打开成功；是否无线送达应看 FPGA 曲谱导入状态或实际声音。点击“断开／离线演示”会先尝试全部释音，再关闭端口。

电脑没有蓝牙时，可使用 Android 经典蓝牙 SPP 串口工具直接发协议。普通 H5 和 iPhone BLE 工具不能直接代替经典蓝牙 SPP。详见同目录接线说明。主程序默认不打开任何物理串口，只有用户主动连接或使用 `--port` 时才打开。

## 数据与验证范围

网页选曲下发仍使用 55 4C / 55 57 / 55 43 协议；实际按键发送 MIDI Note On / Off。板上第 26 段按 S1 停留后使用手机演奏。当前 FPGA 蓝牙演奏入口跟踪一个音符，不把网页八轨或本地 32 振荡器当作蓝牙 32 复音实测。

自动演示不会向网关发送自动 Note On，不生成真人成绩。真人模式才根据真实浏览器输入累计得分；这些分数也不是压力膜或实体琴键测量值。

网关心跳超时约 2 秒会尝试释音。串口断线或蓝牙无线已经中断时，释音可能无法到达 FPGA；必要时复位板卡。当前协议没有板上回传确认，不提供虚构的无线已连接或硬件已验收状态。

验证：`python -m unittest discover -s . -p test_gateway.py -v`（19 项内存串口/HTTP 测试）；`node test_rhythm.cjs`（7 项判定测试）。浏览器测试另附原始记录，覆盖自动演奏、真实键盘、手机布局、32 声部、长按心跳和断网释音。测试不打开物理串口。
