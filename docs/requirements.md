# 赛题要求与工程对应

依据用户提供的 2026 高云赛题官方 PDF 音乐合成器题目页。以下区分实现、仿真与待实测项目。

| 要求 | 工程位置 / 展示 | 验证范围 |
| --- | --- | --- |
| 至少两种独立物理交互维度 | 压力输入、触摸/琴键选音及输入映射 | 模块回归已有，实际部件响应须拍摄 |
| HDL 逐采样实时合成、基础至少四声部 | audio/src/fsr32_engine.v，四音和弦与音色段 | RTL 与数字样本验证；模拟端到端延迟须实测 |
| 拓展 32 独立声部 | 4/8/16/32 声部测试段；独立相位与包络 | 不把谐波数当声部数；不把浏览器音源当 FPGA 音源 |
| 多维表现、多音色、FPGA 效果器 | 力度、滑音、颤音、四音色及效果段 | 相应 RTL 回归与自动演示；真实输入链路另验 |
| 更低延迟及 HDL 可视化 | 波形、Goertzel 频谱、李萨如 | RTL 回归；延迟目标与最终实测值分列 |
| 脱机曲谱与 LED 引导拓展 | SD/FAT32、曲谱导引；LED 为独立历史工程 | LCD 曲谱页面不替代独立 LED 指标 |
| 手机曲谱传输（选做） | phone_app/gateway.py，score_loader_uart.v | 内存串口、9600 UART 与内部回环已测；实际无线待验 |

创新展示重点：同一音频数据的多视图观察、32 声部合成与低资源 ROM、分段自动演示与可重复回归、带失联释音保护的手机控制台、真实按键判定的网页练习模式。创新项的展示同样注明运行平台。
